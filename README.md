# Credit Risk Prediction

### A Classification Model for Borrower Delinquency Risk

Author: Leila Rezaei
Research Interests: Applied Finance, Machine Learning, Data Analysis

---

## 📌 Overview

This project builds a credit risk classification model that predicts whether a borrower
is likely to experience serious financial distress (90+ days delinquent) within the next
two years, based on real historical credit-bureau-style data.

Unlike an earlier version of this project (which used synthetically generated data), this
version uses the **[Give Me Some Credit](https://www.kaggle.com/c/GiveMeSomeCredit/data)**
dataset — a real, publicly available dataset from a Kaggle competition, containing ~150,000
anonymized borrower records.

---

## 🔎 Research Question

Can demographic and credit-behavior variables (utilization, debt ratio, income,
past delinquencies, number of open credit lines) predict which borrowers will experience
serious delinquency within two years?

---

## 📊 Data

| Field | Description |
|---|---|
| `SeriousDlqin2yrs` | Target — 1 if borrower was 90+ days past due within 2 years |
| `RevolvingUtilizationOfUnsecuredLines` | Total balance on credit cards / lines relative to credit limits |
| `age` | Borrower's age |
| `NumberOfTime30-59DaysPastDueNotWorse` | Count of times 30-59 days late |
| `DebtRatio` | Monthly debt payments / monthly income |
| `MonthlyIncome` | Monthly income |
| `NumberOfOpenCreditLinesAndLoans` | Number of open loans/credit lines |
| `NumberOfTimes90DaysLate` | Count of times 90+ days late |
| `NumberRealEstateLoansOrLines` | Number of mortgage/real estate loans |
| `NumberOfTime60-89DaysPastDueNotWorse` | Count of times 60-89 days late |
| `NumberOfDependents` | Number of dependents |

**Source:** Kaggle competition "Give Me Some Credit" (2011), based on anonymized real
consumer credit data.

**Getting the data — no Kaggle login needed:** the notebook downloads `cs-training.csv`
automatically from a public GitHub mirror of the dataset the first time you run it, and
caches a copy in `data/raw/` for next time. If you'd rather get the original file from
Kaggle directly, download `cs-training.csv` from
https://www.kaggle.com/c/GiveMeSomeCredit/data and place it in `data/raw/` — the notebook
will use that instead if it's present.

## 🧪 Methodology

1. Exploratory data analysis — distributions, missing values, class imbalance
2. Data cleaning — imputation of missing income/dependents, removal of invalid ages,
   winsorizing of known outlier columns (documented data quality issues in this dataset)
3. Feature engineering — total past-due count, income-per-dependent, debt-to-income proxy
4. Train/test split (80/20, stratified) with feature scaling
5. Two models trained for comparison:
   - Logistic Regression (interpretable baseline)
   - Random Forest (`class_weight="balanced"` to address the ~6-7% positive class rate)
6. Evaluation using accuracy, precision, recall, F1, ROC-AUC, confusion matrix, and ROC curve
7. Feature importance ranking (Random Forest)

This is correctly framed as a **binary classification / credit scoring problem**
(cross-sectional data, one row per borrower) — not a time-series forecast.

## ⚠️ Limitations

- The dataset is imbalanced (~6-7% positive class) — accuracy alone is not a reliable
  metric; precision/recall/ROC-AUC are prioritized in evaluation.
- This is a methodological demonstration, not a production-ready credit scoring model.
  Real-world deployment would require fairness/regulatory review (e.g., disparate impact
  analysis) that is outside the scope of this project.
